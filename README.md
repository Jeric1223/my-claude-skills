# my-claude-skills

Claude Code에서 반복적으로 쓰는 워크플로우를 **재사용 가능한 스킬(SKILL.md)**로 정리해두는 개인 저장소.

한 번 쓰고 버리는 프롬프트 대신, "이 작업을 시킬 때는 이 순서로, 이 형식으로, 이걸 반드시 검증하고" 같은 판단 기준을 문서화해서 다음에도 같은 품질로 재현되게 만드는 게 목적이다.

## 왜 만들었나

Claude와 대화하면서 여행 일정을 짜봤는데, 결과물 자체는 만족스러웠지만 재현성이 없었다 — 다음 여행을 짤 때 같은 품질을 다시 얻으려면 이전 대화의 맥락과 요령을 처음부터 다시 설명해야 했다. 그 과정에서 실제로 걸렸던 문제(개화 시기 같은 시효성 있는 정보를 잘못 단정한 것, 예약 마감일을 상대 표현으로만 적어서 나중에 다시 계산해야 했던 것)를 규칙으로 못 박아 스킬로 만들면, 매번 같은 실수를 반복하지 않고 결과물 형식도 일관되게 유지할 수 있겠다는 생각이었다.

## 스킬 설계 원칙

- **환각 방지**: 시간에 따라 바뀌는 사실(영업시간, 정기휴무일, 계절 이벤트, 요금)은 모델의 사전지식이 아니라 실시간 검색으로 검증하고, 확인 안 되면 "확인 필요"라고 명시한다. 그럴듯하게 채우지 않는다.
- **결정론적 계산은 LLM에 맡기지 않는다**: 예약 마감일 같은 건 "며칠 전"이 아니라 출발일 기준으로 역산한 실제 날짜로 못 박는다.
- **고정 템플릿**: 매번 다른 형태로 나오면 재사용이 안 된다. 출력 구조를 템플릿 파일로 분리해서 강제한다.
- **모호할 때는 질문한다**: 여행 성격·동행 유형·예산 감각처럼 결과물이 크게 갈리는 조건은 넘겨짚지 않고 구조화된 질문으로 먼저 확인한다.

## 스킬 구조

각 스킬 폴더는 아래 형식을 따른다.

```
skill-name/
  SKILL.md       # 트리거 조건, 절차, 흔한 실수
  template.md     # (필요시) 출력 형식이 고정되어야 하는 경우의 스켈레톤
```
