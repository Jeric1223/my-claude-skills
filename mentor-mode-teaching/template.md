# Mentor Mode — 응답 블록 템플릿

필요한 블록만 골라 쓴다. 한 응답에 개념 설명 → 질문, 또는 피드백 → 꼬리 질문 조합이 보통이다.

---

## A. 개념 설명 블록

```markdown
## 📖 <기술/컴포넌트 이름>이란?

**<한 줄 정의>**

**비유:** <일상 사물에 빗댄 설명>

**동작 흐름**
① <단계>
② <단계>
③ <단계>

**이 프로젝트에서의 역할:** <어디에 끼고 무엇을 책임지는지>
```

필요하면 비교표를 붙인다.

```markdown
| 방법 | 설명 | 문제 |
| :--- | :--- | :--- |
| <대안 A> |  |  |
| <이것> |  |  |
```

---

## B. 질문 블록

```markdown
## 🧑‍🏫 <단계/브랜치 이름> — 질문

> **Q<n>.** <구체적 시나리오로 된 질문>
> (힌트: <한 줄>)
>
> **Q<n+1>.** <질문>
```

### 빈칸 채우기형 (모르겠다고 했을 때)

```markdown
> **Q<n>.** 빈칸만 채워보세요.
>
> 1. <주어진 단계>
> 2. <주어진 단계> [ ? ]건
> 3. [ ? ] 한다
> 4. [ ? ]을 확인한다 → 기대값: [ ? ]
>
> **보너스:** <한 단계 더 생각할 거리>
```

---

## C. 피드백 블록

```markdown
## 🧑‍🏫 Q<n> 피드백

**✅ 맞은 부분:** <사용자 답 인용 + 왜 맞는지>

**🔧 고칠 부분:** <오개념/틀린 연결 고리 + 왜 틀렸는지>

**📖 방금 설명한 내용의 전문 용어**
| 설명한 내용 | 용어 |
| :--- | :--- |
| <사용자가 풀어서 말한 것> | **<용어>** |

**➕ 빠진 부분:** <답에 없지만 알아야 할 핵심>

**🎯 면접용 한 문장 버전**
> "<용어를 써서 압축한 한 문장>"
```

---

## D. 응답 끝 — 대기 중인 항목

```markdown
**아직 답을 기다리는 것**
1. **<결정 이름>:** <예/아니오로 답할 수 있는 한 줄>
2. **<결정 이름>:** <한 줄>
```

여러 번 답이 없었으면:

```markdown
**"ㅇㅇ"** 한마디면 둘 다 반영하고 <다음 단계>로 넘어갈게요.
```
